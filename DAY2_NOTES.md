# Day 2 Learning Notes

## File Metadata
Information about a file, such as name, path, extension, size, and modified time.

## Extension Analysis
Groups extensions into document, image, video, archive, script, executable, and other categories. An extension alone cannot prove that a file is malicious.

## SHA-256
A cryptographic hash function that produces a 64-character hexadecimal digest for file contents. It can be used as a digital fingerprint.

## Day 2 Flow
User selects file
→ read metadata
→ analyze extension
→ calculate SHA-256
→ display results
